# BeadPop 豆豆啵 4.0

> 把喜欢的图片，变成可以亲手拼出来的豆豆图纸。 🧸

**BeadPop** 是一款基于浏览器运行的在线拼豆图纸设计工具。用户可以上传图片，通过智能识别、色彩量化和 MARD 色卡匹配，快速生成拼豆图纸，并在画布中进行逐格编辑、颜色替换、用量统计和作品收藏。

无需安装软件，打开网页即可开始创作。

---

## ✨ 核心功能

### 1. 图片智能转拼豆图纸

支持三种图片导入方式：
- 点击上传本地图片
- 将图片拖拽至上传区域
- 直接使用 `Ctrl + V` 粘贴剪贴板图片

内置四种示例图案：橘猫头像、奶油草莓、彩虹云、蘑菇仔。

提供六种图片识别模式：

| 模式 | 适用场景 |
|---|---|
| 自动识别 | 自动分析图片特征并推荐处理方式 |
| 照片 | 保留照片的光影与色彩过渡 |
| 插画 / 动漫 | 保留干净的平涂色块 |
| 图标 / Logo | 尽可能保留清晰边缘 |
| 像素风 | 适合复古像素图案 |
| 黑白稿 | 将图像转化为黑白灰拼豆图案 |

支持进一步调节：
- 图纸尺寸：最长边 12–120 格
- 画幅：1:1 方形或原图比例
- 色数上限：2–48 色
- 亮度、对比度、饱和度
- 自动去背景与背景容差
- 主体识别
- 线条增强、照片降噪、抖色过渡

### 2. MARD 221 色卡系统

内置 MARD 标准版 221 色参考色卡，包含 9 大色系。

- 查看色号、色名与 HEX 色值
- 按色系筛选颜色
- 搜索色号、颜色名称和 HEX 值
- 只使用常用 80 色
- 可拖动悬浮色卡窗口
- 支持屏幕吸色和原图吸色
- 自动匹配最接近的 MARD 色号，并提供三个候选颜色

### 3. 拼豆图纸在线编辑

生成图纸后，可以直接在画布中修改每一颗豆。

支持五种编辑工具：
- **画笔**：为指定格子添加颜色
- **橡皮擦**：清除指定格子的颜色
- **吸管**：获取图纸已有颜色
- **区域填充**：批量填充相连的同色区域
- **同色替换**：将整张图纸中的某一色号批量替换

其他编辑能力：
- 60 步历史记录，支持撤销与重做
- 网格与色号显示开关
- 实物珠子预览
- 原图对比
- 画布缩放
- 水平镜像、垂直镜像、旋转 90°
- 鼠标悬停自动识别当前格子的色号

### 4. 用量统计与图纸导出

自动统计当前作品的：
- 图纸行列尺寸
- 使用颜色种类
- 拼豆总颗数
- 所需拼豆板数量

拼豆板数量按照 29 × 29 格标准板估算。

支持四种导出格式：

| 格式 | 内容 |
|---|---|
| 图纸 PNG | 完整拼豆施工图，包含网格、色号、标尺、用量图例和原图参考位 |
| 像素图 PNG | 不带网格和色号的纯色像素图，透明背景 |
| 采购清单 CSV | 各色号、色名、色系、HEX 值和所需颗数 |
| 工程 JSON | 保存图纸尺寸、逐格色号等工程数据，方便后续导入编辑 |

### 5. 我的收藏

可以将喜欢的图纸命名并保存到收藏夹。

支持：
- 收藏与更新作品
- 作品重命名
- 删除作品
- 搜索作品名称与色号
- 按修改时间、收藏时间、名称或豆子数量排序
- 重新打开作品继续编辑
- 导入和导出工程 JSON

每个浏览器最多保留 80 件收藏作品。

## 📖 使用教程

### 第一步：上传图片

进入「创作台」，选择本地图片，或者直接使用示例图案开始体验。

### 第二步：设置生成参数

根据图片类型选择识别模式，设置图纸尺寸、画幅和色数。

如果希望照片中的人物或物体与背景分离，可以尝试开启「识别主体」。

如果希望图纸更容易实际制作，可以适当降低色数；如果希望保留更多细节，可以提高色数。

### 第三步：生成图纸

点击「开拼！生成图纸」，等待系统完成图片分析、采样、颜色聚类和 MARD 色号匹配。

生成后即可在中央画布中查看拼豆图纸。

### 第四步：编辑与调整

选择画笔、橡皮擦、填充或同色替换工具，对图案进行修改。

可以点击右侧的「全部 221 色」打开悬浮色卡，也可以利用悬停认色和取色功能快速寻找合适的颜色。

### 第五步：查看用量并导出

在右侧查看各色号所需颗数，根据用量准备材料。

最后选择需要的导出格式，下载图纸、像素图、采购清单或工程文件。

### 第六步：收藏作品

点击「命名并收藏」，为作品设置名称。

之后可以在「我的收藏」中重新打开、修改和管理作品。

## 💻 技术说明

- HTML5
- CSS3
- JavaScript
- Canvas 2D

软件采用原生 HTML、CSS 和 JavaScript 实现，无需安装第三方 JavaScript 依赖，也不需要后端服务器。

图片处理、拼豆图纸生成、颜色匹配、编辑和导出均在浏览器端完成。

### 数据存储

收藏作品使用浏览器 `localStorage` 保存。

**注意：**
- 收藏数据保存在当前浏览器和设备中，不会自动同步到其他设备。
- 清理浏览器网站数据可能导致收藏丢失。
- 建议定期导出工程 JSON 进行备份。
- 工程 JSON 不包含完整原始图片。

### 色卡说明

MARD 221 色卡的 HEX 色值根据官方色卡示意图采样，仅作为屏幕颜色匹配和预览参考。由于显示器、光线及实物材料差异，实际拼豆时建议以实体色卡为准。
